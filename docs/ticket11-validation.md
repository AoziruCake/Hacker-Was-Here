# 資源予算と検出品質の評価結果

検証日: 2026-10-11。[測定前に固定した方法と基準](evaluation-method.md)を、Linux amd64、WSL2系6.18カーネル、Docker管理ボリュームのext4、2 CPU・512MiBコンテナ、ro/nodev/nosuid/noexec、UID/GID 1000・capabilitiesなしで実行した。Go1.27.2 / x/sys v0.49.0 / CGO無効。合成データのみで試験時ネットワークは無効。

## 資源結果

- quick 20,000項目到達: 0.229秒、最初のstdout 0.228秒、最大RSS 8.6MiB、本文9バイト、出力3,027バイト。`enumeration_entries`で不完全状態となった。
- deep 200,000候補: 22.166秒、最初のstdout 22.162秒、最大RSS 34.3MiB、本文2,592,000バイト、出力1,465,388バイト。候補200,000、完全ハッシュ集約後198,001グループ、候補パス2,000件を保持し、`candidate_paths`と`enumeration_entries`を報告した。出力に保持したグループは1,981で、詳細切り詰めと観測グループ数を区別した。
- deep本文境界: 512ファイル、536,870,400バイトを実際に読み、513個目を開始せず0.508秒、最大RSS 8.8MiBで`total_read_bytes`を報告した。
- deep待ち行列: 4,100空ディレクトリを0.068秒、最大RSS 11.7MiBで処理し、`queued_paths`を報告した。
- deep深さ: 深さ64境界の候補を含む65項目を完了し、0.005秒、最大RSS 3.6MiB。
- 大量エラー: 1,000候補を列挙し、permission error詳細を200件保持して`error_paths`と切り詰めを報告。0.016秒、最大RSS 9.8MiB、出力712,006バイト。
- 別実行のFD traceでquickの観測ピーク16、deepの観測ピーク10。標準FDやtrace由来の監視条件を含めても基準40以下だった。

すべて測定前基準を満たした。既存のquick/deep期限、本文・列挙・待ち行列・候補・エラー・出力上限を変更しない。子プロセスのblock input/output操作数は全測定で0だったが、ページキャッシュとsparse入力を含むため物理I/Oなしとは解釈しない。これらは一つの合成環境における値で、厳密なRSS上限、物理ディスクI/O、実データの時間、停止したカーネルI/Oの期限を保証しない。最初のstdoutは完成レポートの出力開始であり、内部検出の瞬間ではない。

## 検出品質

実装前期待を固定した20例で、期待するルール出力は全例一致した。どちらかの内容ルールによる結果は真陽性6、偽陽性1、偽陰性7、真陰性6、precision 85.7%、recall 46.2%で、事前基準80%/40%を満たした。

検出できたのは固定英語表現の複合条件。教育文書内の要求文引用1例を誤検出した。別表現、日本語、HTMLタグで分断した表現を見落とし、UTF-16、不正UTF-8、NUL/ESC入りは契約どおり内容判定対象外だった。対応文字コードでも対応言語・表現でなければ検出できない。小さい合成集合の値を実環境の適合率・再現率として使わない。

初期ルールは変更しない。誤検出や見落としを隠すために単一語へ広げたり、非対応文字コードを安全確認なしに受理したりしない。

## 再現と引き継ぎ

既存の試験イメージをticket11タグで構築後、次を実行する。

```powershell
docker build --progress plain -t hwh-safefs-lab:ticket11 -f tests/safefs/Dockerfile .
./tests/evaluation/run.ps1 -Image hwh-safefs-lab:ticket11
```

`tests/evaluation/`が合成データ、事前基準、公開CLI計測、FD監査、品質集計を保持する。結果JSON、CPUを含む環境記録、hwhバイナリ・固定依存・コーパス・評価ハーネスのSHA-256 manifestは`test-artifacts/`へ回収し、公開・コミットしない。これにより12へ同じ入力と評価対象を特定可能に渡す。評価用コンテナのroot権限はfixture準備と測定管理だけに使い、hwhとstrace対象は非特権・capabilitiesなしで実行する。

この結果でV03とV04の初期版評価、Q15の初期値確定を完了した。12では同じ版とコーパスを対応環境横断の必須試験へ渡す。arm64実機、XFS、下限カーネル、物理環境差は未検証であり、本結果だけで対応済みとしない。
